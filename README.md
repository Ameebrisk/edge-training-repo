# edge-training-repo

Just for fun
Welcome to the **EDGE Training Repository**, a fun and practical resource designed to teach creating Git branching and software workflows using the EDGE teaching model:

- **Explain** the concept clearly
- **Demonstrate** show the user how
- **Guide** learners as they try it
- **Enable** them to work independently

## 📘 What You'll Learn

- How to use Git branches (`git checkout -b`)
- Creates a branch to safely build or change like a "Sandbox".

---

## 🧪 Your First Task: Create a Branch

### ➤ **Explain**

Branches allow you to make changes without touching the `main` branch.

### ➤ **Demonstrate**

Now demonstrate how to create and switch into a branch using the git checkout -b command
